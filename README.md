# 🎬 Netflix 2025: User Behavior Database


## 📘 Project Overview
This project is developed for our term project for the **BLG317E: Database Systems (Fall 2025)** course at Istanbul Technical University.
Our team, Popcoders, designed and implemented a relational database model based on a Netflix user behavior dataset.
The goal is to analyze and organize data about users, their interactions with the platform, and system-generated recommendations, and allow for CRUD operations to be carried out on each class. 

---
## 🧩 Dataset Description
- **Dataset title:** Netflix 2025: User Behavior Dataset
- **Dataset URL:** [https://tinyurl.com/468mthrj](https://tinyurl.com/468mthrj)

The dataset contains information about Netflix users, movies, watch sessions, searches, reviews, and personalized recommendations.
